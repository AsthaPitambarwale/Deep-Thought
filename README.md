## 🛠️ Running Locally

To run this project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/AsthaPitambarwale/Deep-Thought.git
   cd Deep-Thought
````

2. **Open `index.html` in your browser**

   You can either:

   * Double-click the file
   * Or run a local web server (recommended)

   ```bash
   npx http-server .
   ```

3. Visit `http://localhost:8080` (or whatever URL your server indicates).
